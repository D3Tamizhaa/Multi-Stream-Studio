# Multi Stream Studio

A browser-based multi-platform streaming studio built with React and Vite.

## Features

- Login screen
- Editor workspace
- Editable canvas
- Scene management
- Source management
- Image source
- Browser source
- Media source
- Text source
- Source visibility
- Source locking
- Source layer ordering
- Drag sources around the canvas
- Audio mixer
- Platform management
- YouTube
- Twitch
- Facebook
- Kick
- Custom streaming destination
- Start / End Streaming controls
- Uptime
- Bitrate
- FPS
- CPU
- RAM
- Authorization settings
- Stream settings
- Output settings
- Audio settings
- Video settings
- Advanced settings
- LocalStorage persistence
- Responsive UI
- Dark studio interface

## Requirements

Node.js 20+ recommended.
