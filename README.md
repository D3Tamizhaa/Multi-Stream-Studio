# Multi Stream Studio

Lightweight web UI/server for a browser-based streaming studio.

## Features

- Live edit canvas
- Scene management UI
- Source management UI
- Audio mixer
- Streaming platforms
- Start/stop streaming controls
- Usage/status panel
- Authorization settings
- Stream settings
- Output settings
- Audio settings
- Video settings
- Advanced settings
- Responsive layout

## Requirements

Node.js 18+

## Run

```bash
npm start
