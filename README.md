# Multi Stream Studio

A lightweight browser-based UI for Multi Stream Studio.

## Features

- Live editing canvas preview
- Scene management
- Source management
- Image source
- Browser source
- Media file source
- Text source
- Audio mixer
- Platform management
- Streaming controls
- Usage monitoring
- Authorization settings
- Stream settings
- Output settings
- Audio settings
- Video settings
- Advanced settings
- Responsive layout
- No framework
- No build system
- No external dependencies

## Run

Simply open:

    index.html

in a modern browser.

For local development, you can also use any static HTTP server.
